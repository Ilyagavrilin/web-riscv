Load a bare-metal ELF

In Debugger, choose an ELF file or drop it into the loader. The file is saved in your browser's local ELF library. Nothing is sent to a server. Reload it from the library at any time, or remove the saved copy.

Use ELF32, little-endian, machine RISC-V, executable type ET_EXEC, with entry at 0x200. Every PT_LOAD segment must fit in 64 KiB RAM. BSS is zero-filled. The loader shows segment addresses, executable bytes, basic disassembly and any PC breakpoints you set. Unknown compressed encodings appear as .hword; the hardware still executes them.

Compile for the selected profile: -march=rv32imc -mabi=ilp32, -march=rv32ic -mabi=ilp32, or -march=rv32ec -mabi=ilp32e. Supply a linker script and startup code that initializes your stack. There is no operating system or syscall emulation. Write an exit code to 0xF0000004 to finish, or write bytes to 0xF0000000 for UART.

Changing profiles reloads the active image into a fresh CPU. Reset reloads the same ELF, even when the assembly editor contains different text.

Write a Wasm MMIO module

A peripheral is an independent Wasm instance. It receives register offsets and naturally aligned byte widths from accepted CPU data-bus requests. It does not import the CPU module or modify SCR1. Multiple instances can occupy different windows, including multiple instances of the same file.

SystemC device SDK

All three example devices are real SystemC modules, linked against the pinned Accellera SystemC 3.0.2 kernel. Write C++17 register behavior and an SC_METHOD sensitive to clk.pos(). You do not write Wasm exports or manually call the clock method. 

#include <scr1/device.hpp>
class Counter final : public scr1::ClockedDevice<1> {
public:
  explicit Counter(sc_core::sc_module_name name) : ClockedDevice(name) {
    SC_METHOD(count);
    sensitive << clk.pos();
    dont_initialize();
  }
  void count() { ++registers_[0]; }
};
scr1::Device& scr1::device() noexcept {
  static Counter instance{"counter"};
  return instance;
}

read(index) may have side effects; inspect(index) const must not. write(index, value, mask) receives a word-aligned value and byte-lane bitmask. Call store(index, value, mask) for a normal masked register write; override it for read-only or write-one-to-clear registers. Indices are word register numbers.

The adapter binds a SystemC signal to clk. Each accepted CPU request updates bus-visible state, then the kernel advances a low and a high half-cycle of 500 ps each, settling delta cycles. A model therefore receives one positive edge per simulated CPU clock. Browser timers and UI refresh do not drive the device. Each Wasm instance owns an independent SystemC kernel.

This browser build supports clocked SC_METHOD models, signals and delta-cycle evaluation. Coroutine SC_THREAD/SC_CTHREAD models are not supported by the single-threaded host. No SharedArrayBuffer or cross-origin-isolation headers are needed. A small host provides only empty environment/stdin and bounded diagnostic stdout/stderr; it grants no filesystem, network or wall-clock access.

New clocked examples

Timer: +0x00 control (bit 0 enable, bit 1 periodic), +0x04 period, +0x08 elapsed, +0x0C sticky match (write 1 to clear). Zero period becomes one. One-shot stops at the match; periodic mode resets elapsed. Poll the flag; an external interrupt connection is not present yet.

Mailbox: +0x00 TX, +0x04 RX (read pops), +0x08 status, +0x0C control (bit 0 enable, bit 1 flush command). Status bits 3:0 give RX depth; bits 8/9 mean full/empty, bit 10 is sticky overflow (write 1 to clear), and bit 11 is pending TX. A staged TX word transfers into the eight-word FIFO on the next enabled clock edge. Inspection never consumes data.

ABI v1

uint32_t mmio_abi_version(void); // required: return 1
uint32_t mmio_size(void);        // required: window size in bytes
void mmio_reset(void);          // required: restore device state
uint32_t mmio_read(uint32_t offset, uint32_t width);
void mmio_write(uint32_t offset, uint32_t value, uint32_t width);
void mmio_tick(uint32_t clocks); // optional: clocks elapsed
uint32_t mmio_inspect(uint32_t aligned_offset); // optional: no side effects

All values use Wasm i32. Width is 1, 2 or 4 bytes; data is little-endian. Read/write run before the accepting rising edge, then mmio_tick(1) runs after it. A write that enables a counter therefore enables counting on that edge. Inspection must never consume FIFOs, acknowledge interrupts or otherwise change device state.

Build and attach

Start with the working C example below. The CMake target links SystemC and exports the device ABI automatically; module authors write neither Wasm exports nor JavaScript glue. 

nix build .#peripherals

Open Devices, set an unused base such as 0x40000000, and choose your .wasm file. Windows must be word-aligned, 4–65,536 bytes long, outside RAM and the UART/exit window, and must not overlap another device. Using an existing base atomically replaces that instance after validation. Rejected files leave existing devices intact.

Working GPIO / counter example

Offsets: +0x00 GPIO, +0x04 rotation period, +0x08 elapsed active clocks, +0x0C enable bit. Select the built-in module and attach it, then load the counting demo. The CPU executes a loop, reads the peripheral and saves GPIO at 0x1000 and elapsed clocks at 0x1004. Use diagnostic mode to follow each access.

Lifecycle and faults

CPU reset resets every attached device. Replacing a device resets only that device and preserves CPU state. Detach returns its address window to unmapped memory. A read/write Wasm trap detaches the failing instance and returns a bus error to SCR1. Other devices remain attached. A tick failure pauses execution with an error. Run bounded code in callbacks; an infinite callback requires restarting the worker. There is currently no external interrupt, DMA, asynchronous host I/O, or DAP/GDB transport in this ABI.

Read a diagnostic capture

Enable diagnostic mode before the workload. Memory and MMIO events contain cycle number, current PC, address, width, bus data and response. Retirement events contain the completed PC and register changes. Enable fetch logging separately when investigating instruction access errors. Device attach/detach, exit, breakpoint and trap events are recorded independently of diagnostic mode.

The trap panel shows faulting PC, cause and trap value; machine CSRs are sampled directly from SCR1. JSON export includes retained events, registers, RAM window, device state and bus samples. Events have a monotonically increasing sequence number; a dropped-event count makes bounded retention explicit. VCD covers sampled bus signals rather than every internal RTL signal. The bench stops before the trap handler executes.

Assembly reference

GNU as and ld 2.46.0 support standard RISC-V syntax, directives, macros, expressions, relocations and ISA checks. The editor links a real ELF at 0x200. It defaults to .option norvc for predictable instruction widths; add .option rvc for compressed emission. Supported hardware extensions depend on the selected SCR1 profile.

Ctrl/⌘+Enter assembles, Alt+→ steps an instruction, Escape pauses. PC breakpoints stop before a clock; continuing skips the current address until PC changes.

About this workbench

Model and build

Unmodified Syntacore SCR1 RTL is compiled by Verilator and Emscripten into three separate WebAssembly models. Execution and peripherals run in browser workers. Nix pins the source and toolchain; CMake, Ninja and CTest handle building and testing. This page requires no account or backend service.

Scope

MAX, BASE and MIN are upstream recommended configurations. They differ in ISA, pipeline bypasses and optional facilities. CPI includes startup clocks with one-clock memory replies; it is not physical chip frequency, area or power. RAM is 64 KiB. External interrupts and JTAG are held inactive. MIN begins with zero-initialized two-state model storage, although its hardware register file has no reset.

Comparison stops at 30,000 clocks or 4,096 retirements per profile. Final-state matches require completed runs; trapping and bounded runs are incomplete. Register comparisons use the shared architectural register set.
