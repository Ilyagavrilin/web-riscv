BRING YOUR OWN PROGRAM

From a loop to a lesson.

The editor supports a focused RV32IM assembly subset. For full RV32IMC, load a bare-metal ELF32 linked at 0x200. RAM spans 0x0000–0xFFFF; store an exit code at 0xF0000004 to stop.

Assembly reference & keyboard shortcuts

Base: add/sub, shifts, comparisons, and/or/xor, immediate variants, loads/stores, branches, lui/auipc, jal/jalr, ecall/ebreak/wfi. M: mul, mulh, mulhsu, mulhu, div/divu, rem/remu. Pseudo: li, la, mv, j, ret, nop, beqz/bnez. Use labels, ABI register names or x0–x31, .word, decimal/hex integers and # comments. Other directives, expressions, CSR mnemonics and compressed assembly require an external assembler. Ctrl/⌘+Enter assembles; Alt+→ steps; Escape pauses. Editing requires assembling again. Traps stop the bench for inspection.
